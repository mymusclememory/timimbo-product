Case study 01 · Product design + AI

Muscle Memory

A strength training app I designed, built and shipped solo with AI as my engineering partner. Then I extended it into a gym platform that turns any facility's equipment into personalized workouts.

Role
Founder, product designer, creative director
Platform
Progressive web app
Stack
React, Supabase, Netlify, Claude API
Live
mymusclememory.app

The problem

Serious lifters were tracking in notes apps and spreadsheets.

Most fitness apps chase beginners with streaks and badges. Lifters running real programs like PHAT, Upper/Lower or Push Pull Legs needed something faster: log a set in one tap, rotate programs on schedule, and never lose their history.

My approach

Design it like a product, build it like a studio of one.

I owned every layer: brand, design system, UX flows, specs and launch. Design decisions came from my own training floor and beta tester feedback, and I turned them into specs that Claude Code built from.

Design system

Built for a dim gym and a sweaty thumb.

A dark interface with two signal colors: ember for power days, glacier for hypertrophy days. Barlow Condensed keeps numbers big and scannable between sets.

Key features

Small interactions, solved carefully.

01

Program rotation

Rotate whole programs on a schedule. Every new cycle restarts at Day 1, so nobody loses their place.

02

Long-press supersets

Hold an exercise to link it to the next. Three gestures kept distinct: scroll, open and link, tuned for left- and right-handed lifters.

03

Exercise swap

Machine taken? Swap it mid-workout. A SWAPPED badge keeps the history honest.

04

Recall coaching notes

Inline notes read your last session and tell you what to do next: move up, hold, or back off a stalled lift. Plain rules, no AI, so the advice is always predictable.

05

Local-first with cloud backup

Workouts save on the phone and work offline. A one-time email code turns on backup, which syncs workouts and body weight across devices. No password.

06

Three-door onboarding

Get a recommended program, build your own, or import one. Experience level shapes how much the app explains.

Screens show seven weeks of sample training data, loaded into the real app.

How AI is used

AI on both sides: building the product and inside the product.

Building it

Claude Code as engineering partner

I write the specs and Claude Code writes the code. I also run audit passes: AI reports bugs and UX pain points first, and nothing gets fixed until I've reviewed the findings. The full loop is in the Process section below.

Inside it

Photo-to-program import

Signed-in lifters can snap a photo of a whiteboard or a coach's program, and Claude reads it into an editable draft. Pasted text, .txt files and PDFs are parsed right on the phone.

My rule: the AI parses, it never authors. The lifter stays in control of every set.

Process

Specs in, reviewed software out.

I design and direct, and Claude Code writes the code. Every change runs through the same loop, and nothing reaches the live app until I've seen it working.

  1. I write the spec

    The problem, the flow, the edge cases and what done looks like. Most of it comes from my own sessions on the gym floor and from beta tester feedback.

  2. Claude Code builds on a branch

    Each change is built on its own branch, so the live app is never touched while work is in progress.

  3. I review a deploy preview

    Every branch gets a working copy of the app at its own link. I test it the way a lifter would, on a real phone.

  4. Then it merges

    Only after I sign off does the change merge and ship. Audit passes follow the same rule: findings first, fixes only once I've reviewed them.

Extension · Gym platform

America's Gym: when 100+ machines outgrow a personal tour.

The owner of America's Gym in Wheeling, IL used to walk every new member around the floor and show them each machine. After growing past 100 pieces of equipment, that stopped being possible, and new members felt intimidated by gear they didn't know how to use.

I designed a facility layer for Muscle Memory, with America's Gym as the pilot. The gym supplies its equipment list and the app builds workouts from what's actually on the floor, with the owner's own demo videos as tutorials.
