Case study 02 · Product design + AI

BannerFactory

One upload in, a full set of on-brand display banners out. A web app I designed and built to take the repetitive resizing work off a CPG creative team.

Role
Product designer, product owner
Output
16 standard ad sizes per upload
Stack
Next.js, TypeScript, Tailwind, Konva
Built with
Claude Code, from my specs

The problem

Every campaign meant rebuilding the same banner fifteen times.

Display campaigns need a banner for every placement, from a skinny 320×50 mobile strip to a 970×250 billboard. Designers were hand-resizing each one, re-checking logos, badges and legal copy every time. Skilled people, spending hours on production instead of ideas.

My approach

Turn the design system into software.

I'd already built a multi-size banner design system in Figma. BannerFactory encodes those layout rules in code, so the system makes the decisions a designer used to make by hand: where the product sits, how the headline scales, where the badge goes.

How it works

Three steps from assets to export.

1

Upload once

Product image, logo, headline, and certification badges like Non-GMO or Informed Sport, plus a brand category.

2

Auto-layout every size

A canvas layout engine places each element per size using rules from the design system. Preview everything at once and fine-tune any one.

3

Batch export

Download the full set as one ZIP, named and sized for upload to Amazon DSP or any other ad platform.

Every size is checked as you work. The tool flags any size where text had to shrink or the button got too small, before anything is exported.

One asset, every placement

The same creative, laid out for each size by rule.

Real output from a single upload, shown at reduced scale. Field & Co. is a sample brand made for this case study.

How AI is used

A designer shipping software, with AI doing the heavy lifting in code.

Building it

Spec-driven development

I don't write the code. I write precise product specs, layout rules and acceptance criteria, then direct Claude Code to build them and review the result. Design thinking stays the bottleneck, not engineering hours.

Where it's going

Creative that learns from results

Next: import ad performance data so the tool can recommend which creative to run, with built-in A/B testing to prove it.

Roadmap

From an internal tool to a product for lean brand teams.

Brand admin portal

Approved taglines and assets in one place, so every banner starts on-brand.

Shared team library

Shared accounts, templates and asset library for a whole creative team.

Partner portal

Retailers and vendors pull brand-approved materials themselves.

White label

A version for CPG companies with limited design resources.
